## 🚀 Quick Start Guide

### 1. View API Documentation
```bash
# Read comprehensive course documentation
cat API_DOCUMENTATION.md
```

### 2. Run Python Simulation
```bash
# Interactive mode
python3 park_runner.py

# Follow prompts:
# - Enter runner name
# - Choose fitness level (beginner/average/good/excellent)
# - Use commands: run, step, status, break, auto, park, quit
```

### 3. Open Visual Simulation
```bash
# Method 1: Direct file opening
open park_runner_visual.html

# Method 2: Local server
python3 -m http.server 8000
# Then visit: http://localhost:8000/park_runner_visual.html
```

### 4. Read Complete Usage Guide
```bash

cat USAGE_GUIDE.md
```

## 🎮 Simulation Features Demonstrated

### Weather System
- **Sunny**: Optimal conditions (100% speed, normal energy)
- **Cloudy**: Slightly reduced performance (95% speed, 90% energy drain)
- **Rainy**: Challenging conditions (80% speed, 120% energy drain)

### Trail Difficulties
- **Easy**: Paved paths, good for beginners
- **Moderate**: Mixed terrain, balanced challenge
- **Hard**: Hills and difficult surfaces

### Fitness Levels
- **Beginner**: 70% speed, 60% endurance
- **Average**: 100% speed, 100% endurance (baseline)
- **Good**: 130% speed, 140% endurance
- **Excellent**: 160% speed, 180% endurance

### Achievement System
- 🏆 **Distance Milestones**: 100m, 1K, 5K, 10K
- 🏆 **Speed Records**: Running > 10 km/h, > 12 km/h
- 🏆 **Endurance Goals**: 30 minutes, 1 hour continuous
- 🏆 **Special Events**: Random discoveries and challenges
